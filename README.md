## Sobre mí

Estudiante del último semestre de **Ingeniería en Sistemas** en la Facultad de Ciencias y Tecnologías (FCyT - UNCA) y profesional en el área de operaciones de red y monitoreo de sistemas. ## Proyectos Destacados

Desarrollo de proyectos personales, académicos y de investigación enfocados en automatización, visión artificial y plataformas web:

* **Detección de Uso de Casco en Motociclistas (Computer Vision):** Prototipo de sistema inteligente desarrollado con Python, PyTorch, OpenCV, YOLOv8/v9 y DeepSORT con aceleración por hardware (CUDA) para el análisis de tráfico urbano y generación automatizada de pre-evidencias digitales.
* **Cliente Web para Repositorio Institucional (DSpace):** Interfaz web moderna construida con Next.js, TypeScript y Tailwind CSS para el consumo de la API de DSpace de la FCyT UNCA, optimizando la búsqueda académica mediante filtrado multicriterio avanzado.
